Option 1: WordPress Chatbot Plugin Settings

In WordPress Admin ➔ Chatbot Settings ➔ set Backend URL to:

http://localhost:3001
Option 2: Website Tracking Tag (Clarity & Chatbot Telemetry)

Add this script before the closing </body> tag on any RVCE webpage:

<script>
  window.RVCE_TELEMETRY_URL = "http://localhost:3001";
</script>
<script src="http://localhost:3001/clarity-telemetry.js"></script>
